# 中秋動畫｜新對話用提示詞與動畫要求

> 這份整理了使用者在前一段對話中確認過的要求，還有被否決過的做法。新對話請以這份為準。

## 一、可以直接貼到新對話的提示詞

```
請幫我製作一支「中秋節的故事：后羿射日與嫦娥奔月」兒童動畫。
要做得像動畫工作室真的為孩子製作的作品，適合親子一起看。

【規格】
- 直式 9:16，1080×1920，30fps，總長 60 秒內
- 產出一支可直接下載的 MP4，不需要預覽網頁

【畫面風格】
- 全片跟我的第 1 幕分鏡圖同一種風格：柔和 3D 卡通渲染、Q 版比例、大眼睛有高光、
  溫暖的電影感光線，要有質感
- 不要黏土風、不要紙雕剪紙、不要 2D 扁平向量、不要把去背圖片貼上去平移
- 色系取自分鏡圖：溫暖月夜色調，奶油、杏橘、奶茶粉、可可棕、薰衣草紫、霧藍、夜空藍
- 角色清楚可愛、比例正確、不能變形（不能多頭、多手、雙弓），同一個角色每一幕都要長得一樣

【構圖】
- 手機直式觀看，人物不能過大
- 主視覺放在畫面置中或置中偏上
- 不要碰到直式短影音安全區：上方約 250px、下方約 500px、右側約 180px 只放背景
  （主體範圍約 x 90～900、y 250～1420）

【動畫】
- 角色要真的動起來（表情、動作、衣帶頭髮飄動），可以用定格動畫的節奏
- 每一幕之間的轉接必須絲滑
- 鏡頭要有運鏡（推近、拉遠、平移）
- 畫面動作要對齊旁白，例如講到「咻」的瞬間箭射出

【故事與角色】
- 第 1 幕：直接使用我提供的分鏡圖（媽媽抱著熊寶在床上，窗外滿月）。
  人物和構圖不改，只加輕微運鏡和光影呼吸。
- 第 2 幕起媽媽和熊寶不再出現，只出現故事角色：后羿、嫦娥、玉兔、村民、太陽
- 6 幕：
  1 床邊開場
  2 天上十個太陽，大地乾裂，大家好熱
  3 后羿爬上山，拉弓射下九個太陽，只留一個
  4 大家請后羿當國王，他變兇，拿到仙丹
  5 嫦娥擔心，偷吃仙丹，飄上月亮
  6 大家賞月吃月餅，月亮上有嫦娥和玉兔

【旁白】（中文、台灣口語，不附英文翻譯）
1 今天中秋節～ 媽媽說個中秋節故事給你聽～
2 很久很久以前，天上竟然有十個太陽！好熱好熱，土地都乾到裂開了，大家熱得受不了。
3 這時候，射箭高手后羿出現了！他爬上高高的山，拉弓，咻！咻！咻！一口氣射下九個太陽，只留一個，每天乖乖上班下班。
4 大家好開心，請后羿當國王。可是他越來越兇，還拿到了吃了會長生不老的仙丹。
5 他的太太嫦娥好擔心，趕快偷偷把仙丹吃掉。咦？身體變得輕飄飄的，一路飛呀飛，飛到了月亮上！
6 所以每年八月十五，月亮最圓的時候，大家就一起賞月、吃月餅，想念善良的嫦娥。這就是中秋節最有名的傳說喔！

【聲音】
- 只有旁白：台灣口音女生，活潑、溫柔的說故事語氣，全片同一個聲音
- TTS 用 Voai 或 Gemini TTS
- 不要配樂、不要字幕、畫面上不放任何文字

【流程】
- 先給我看角色設定與每一幕的關鍵畫面，我確認後才做完整動畫
- 輸出前逐幕截圖檢查：比例、變形、重疊、安全區
```

## 三、已經被否決的做法（新對話不要再走）

| 版本 | 做法 | 否決原因 |
|---|---|---|
| v1 | 簡單合成 | 品質不行 |
| v2 | AI 生圖去背後貼上場景平移 | 簡陋、像拼貼 |
| v3 | 程式繪製 SVG 向量角色 | 不是分鏡圖的 3D 質感 |
| v4 測試 | 紙雕剪紙風 | 使用者不要紙雕 |
| v4 | AI 靜態 3D 插畫＋鏡頭推移、分層視差、光效（動態繪本） | 「動畫方式錯了」，角色沒有真的在動 |

## 四、給新對話的技術提醒

- 前一段對話的雲端環境**沒有 GPU**，只能生靜態圖，做不出角色真正會動的 3D 動畫。這是四版都卡住的根本原因。
- 要達到「角色真的會動、像分鏡圖的 3D 質感」，實際可行的路線是「**圖生影片**」（image-to-video）。
  - 做法：先用分鏡圖風格生出每一幕的關鍵畫面（角色定稿、一致），再用影片模型讓畫面動起來。
  - 工具：可以用 Kling、Runway、Hailuo、Veo 這類服務，或是在有 GPU 的環境跑開源的 Wan 圖生影片模型。
  - 最後把每幕影片、旁白和轉場剪在一起。
  - 這是我的建議，新對話可以先確認手上有哪個工具能用。
- 角色一致性：先做角色設定圖（后羿、嫦娥各一張正面定稿），之後每個畫面都以設定圖為參考生成。
- 旁白用 Voai 或 Gemini TTS 都需要 API key，要設在環境變數，不要貼在對話裡。
- 開源的 BreezyVoice 不用 key 也能做台灣口音。但它模仿參考音的語氣，官方範例是朗讀腔，不夠活潑。要活潑，請準備 8～10 秒自己用講故事語氣錄的參考音。
